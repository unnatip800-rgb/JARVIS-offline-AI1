==================================================
JARVIS - OFFLINE AI ASSISTANT
==================================================

JARVIS is a private offline AI assistant powered by
Ollama and Llama 3.2 3B.

--------------------------------------------------
FIRST-TIME SETUP
--------------------------------------------------

1. Install Python 3.14 or a compatible Python version.

2. Install Ollama.

3. Make sure Ollama is running.

4. Download the JARVIS model:

   ollama pull llama3.2:3b

5. Open this folder.

6. Double-click:

   jarvis.bat

JARVIS will open automatically in your browser.

--------------------------------------------------
NORMAL USE
--------------------------------------------------

After setup, simply double-click:

   jarvis.bat

You do NOT need to open a terminal manually.

--------------------------------------------------
OFFLINE USE
--------------------------------------------------

JARVIS itself runs locally.

After Python, Ollama, the required Python packages,
and the Llama model have been installed, an internet
connection is not required to use JARVIS.

--------------------------------------------------
FEATURES
--------------------------------------------------

- Offline AI chat
- Conversation history
- Long-term memory
- Document Q&A
- Study tools
- Coding assistant
- Local tools
- PDF support
- Local Ollama/Llama model
- Private local data

--------------------------------------------------
IMPORTANT
--------------------------------------------------

The first installation requires internet access to
download the required software/packages/model.

Your conversations and memories are stored locally.

Do not delete the "data" folder while JARVIS is running.

--------------------------------------------------
TROUBLESHOOTING
--------------------------------------------------

If JARVIS says it cannot connect to Ollama:

1. Make sure Ollama is running.
2. Open a terminal and run:

   ollama list

3. Make sure "llama3.2:3b" is installed.

If necessary:

   ollama pull llama3.2:3b

Then start JARVIS again using:

   jarvis.bat
